# Roam Landing

The landing app is the public marketing site for Roam.

```bash
pnpm --filter @roam/landing dev       # http://localhost:3011
pnpm --filter @roam/landing build
pnpm --filter @roam/landing lint
pnpm --filter @roam/landing typecheck
```

The product app lives in `apps/web`; use the root `pnpm dev` command for the
consumer storefront.
